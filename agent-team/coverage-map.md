# Production Role Coverage

- **Executive Producer:** I do this myself; I make gate, scope, and ship decisions.
- **Creative Director:** I do this myself; I approve the game fantasy, visual direction, and tone.
- **Producer / Tracker:** `agents/pm.md` maintains milestones, risks, weekly PPP, evidence links, and the living handoff; I retain scope and gate decisions.
- **Design Lead:** `agents/art-design-lead.md` turns evidence into approved mechanics, interaction, UI, and level-readability briefs.
- **Tech Lead:** `agents/tech-lead.md` implements approved game rules on branches and hands builds to QA.
- **QA:** `agents/qa.md` independently tests GDD rules and writes only under `tests/`.
- **Art:** `agents/art-design-lead.md` owns visual direction and concept specifications; I approve every direction and final asset.
- **Audio:** I do this myself; a separate audio agent is not justified by current scope or repeated friction.
- **In-game Commander:** Separate runtime game agent; it does not count as a production agent.
